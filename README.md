# Enlil Center Iraq Data Hub

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.23240940.svg)](https://doi.org/10.5281/zenodo.23240940)

Open data on Iraq's climate, water, energy, economy and governance, published by the [Enlil Center for Environment and Sustainable Development](https://enlilcenter.org), an independent research centre in Baghdad.

This repository mirrors the [Enlil Center Iraq Data Hub](https://enlilcenter.org/data). Each series has an interactive chart, its source and scope notes on its page there; here you get the same series as plain CSV files with a machine-readable [Frictionless Data Package](https://datapackage.org/) descriptor (`datapackage.json`).

Last updated: 2026-10-27

## How the data is put together

- Series are pulled from the original publisher's API or release wherever one exists (World Bank World Development Indicators, World Bank Global Gas Flaring Reduction Partnership, Ember, IRENA, IMF, IOM Displacement Tracking Matrix). Report tables are transcribed from the cited report.
- Each series in `datapackage.json` records its unit, frequency, source URL, retrieval date and scope notes (for example, when a series covers southern seaborne exports only, or when a new edition re-estimates past values).
- Values are not adjusted or modelled by Enlil. Where a source revises its numbers, the next update here follows the revision.
- Spotted an error? Open an issue or write to info@enlilcenter.org.

## Using the data

```python
import pandas as pd
gdp = pd.read_csv("https://raw.githubusercontent.com/enlilcenter/iraq-data-hub/main/data/iraq-gdp-current-usd.csv")
```

Or load every series with its metadata through the data package:

```python
from frictionless import Package
pkg = Package("datapackage.json")
```
